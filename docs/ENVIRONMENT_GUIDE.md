# 배포 후 다음 단계와 환경변수 안내

작성일: 2026-09-29

## 현재 상태와 다음 진도

사용자가 Vercel 배포 성공을 확인했다. 운영 주소는 https://tue111-everyday-voca.vercel.app 이다. 배포 성공과 실제 학습 저장·휴대폰 음성·알림 검증은 별도이며, 이번 문서 작성에서는 운영 검증을 실행하지 않았다.

| 순서 | 다음 작업 | 완료 기준 |
|---|---|---|
| 1 | 배포 상태 확인 마무리 | 운영 배포 커밋, 페이지와 API 응답, 최신 오류 로그 확인. `/api/health` 성공만으로 DB 연결을 판정하지 않는다. |
| 2 | 알려진 콘텐츠 품질 수정 | 한국어 해설에 남는 빈칸 방지, 미국식 포장 음식 표현 개선, 하루 세트의 유사 표현 중복 개선. 기존 학습 기록과 게시된 세트는 보존한다. |
| 3 | 수정 검증과 반영 | 시나리오 → 구현 → 관련 테스트 → 전체 `npm run verify` → PROGRESS 기록. 푸시 범위를 정한 뒤 사용자가 재배포한다. |
| 4 | 운영 학습 흐름 검증 | 별도로 정한 검증 계정으로 가입, 카드 10개, 퀴즈 10개, 완료·복습, 새로고침 후 유지, 다른 기기 복구 확인. |
| 5 | 휴대폰 음성 검증 | iPhone·Android에서 표현/예문, 1.0배·0.85배, 카드 이동 시 중단, 실제 발음과 캐시 확인. |
| 6 | 알림·예약 검증 | VAPID 설정, 설치·알림 허용, 앱 종료 상태 수신, 클릭 이동, 예약 실행 기록, 중복 방지와 완료자 제외 확인. |
| 7 | 비용·백업·사용성 확인 | 제공자 실제 사용량과 앱 추정 장부 비교, 백업·별도 DB 복구 검증, 2주 사용 후 복습 효과 평가. |

자동 테스트는 격리 저장소와 가짜 AI·푸시·음원을 사용한다. 실제 AI 새 30문항 검토, 유료 음성 생성, 운영 DB 쓰기, 실제 알림 발송은 범위를 정해 별도로 진행한다.

## 질문

등록한 환경변수 중 API 키와 DB URI를 제외한 나머지 변수는 왜 등록하며, 각각 어떤 역할인가? 왜 `.env`에는 들어 있지 않은가?

## 답변: 환경변수는 실행 환경별 설정이다

환경변수는 코드 밖에서 앱의 동작을 정하는 설정이다. 비밀정보뿐 아니라 사이트 주소, DB 이름, 비용 제한 같은 일반 설정도 포함한다. 코드를 고치지 않고 로컬과 운영 환경에 서로 다른 값을 적용할 수 있다.

현재 로컬 `.env`에는 변수 이름 기준으로 `OPENAI_API_KEY`, `MONGODB_URI`, `MONGODB_DATABASE` 세 항목이 있다. 실제 값은 이 문서에 기록하지 않았다. Vercel에 현재 등록된 전체 목록은 직접 조회하지 않았으므로 아래 표는 배포 안내에서 다룬 변수와 프로젝트가 지원하는 추가 변수를 설명한다.

### 배포 안내에서 다룬 변수

| 변수 | 역할과 등록 이유 | 생략하면 / 로컬에서는 |
|---|---|---|
| `MONGODB_DATABASE` | 연결한 MongoDB 서버 안에서 사용할 DB를 선택한다. URI가 서버 연결 정보라면 이 값은 저장할 DB 이름이다. 현재 앱은 이 값을 DB 선택에 사용한다. | 코드 기본값은 `everyday_voca`. 기존 데이터와 같은 DB를 명확히 선택하기 위해 등록한다. 현재 로컬 `.env`에도 있다. |
| `APP_URL` | 앱의 기준 주소다. 서버는 답안 제출 등 POST 요청의 출처가 이 주소와 같은지 확인한다. | 로컬 기본 허용 주소는 `http://127.0.0.1:5173`. 운영에서는 HTTPS 주소가 필수이며 현재 운영 주소로 설정해야 한다. |
| `CRON_SECRET` | 예약 작업 요청을 인증하는 공유 비밀값이다. 외부인이 콘텐츠 생성·알림 작업을 임의 실행하지 못하도록 서버가 검사한다. | 이 앱은 운영에서 32자 이상을 요구한다. 로컬 서버 시작에는 필요 없지만 예약 API를 직접 호출하려면 로컬에도 설정이 필요하다. |
| `AI_MONTHLY_BUDGET_USD` | 콘텐츠 생성에 사용할 월간 추정 예산이다. 서버가 생성 작업의 예산 예약·허용 여부를 판단한다. | 생략 시 코드 기본값 `3`달러. 등록하면 원하는 제한을 명시적으로 관리할 수 있다. |
| `TTS_MONTHLY_BUDGET_USD` | 음성 생성의 월간 추정 예산이다. 콘텐츠 생성 예산과 별도로 관리한다. | 생략 시 코드 기본값 `1`달러. |

Vercel은 `CRON_SECRET`을 예약 호출의 인증 헤더에 자동으로 넣고, 앱은 자신의 환경변수와 비교한다. 변수 이름은 정확히 `CRON_SECRET`이어야 한다. 이 값은 예약 실행 시각을 정하지 않으며, 실행 시각은 `vercel.json`에 정의된다. [Vercel 예약 작업 인증 안내](https://vercel.com/docs/cron-jobs/manage-cron-jobs#securing-cron-jobs)

두 예산 변수는 앱 내부의 추정 비용 제어다. OpenAI 계정 전체의 실제 청구 한도를 설정하는 값이 아니며, 다른 앱에서 사용한 비용도 제어하지 않는다.

### 알림 기능용 변수

| 변수 | 역할 | 설정하지 않으면 |
|---|---|---|
| `VAPID_PUBLIC_KEY` | 브라우저가 이 앱의 푸시 알림 구독을 생성할 때 사용하는 공개키. | 세 항목 중 하나라도 빠지면 실제 푸시 준비가 완료되지 않은 것으로 처리한다. |
| `VAPID_PRIVATE_KEY` | 서버가 알림 발송 주체를 증명할 때 사용하는 개인키. 공개키와 한 쌍으로 생성하며 서버에만 보관한다. | 실제 푸시 발송에 사용할 수 없다. |
| `VAPID_SUBJECT` | 푸시 서비스가 발송자에게 연락할 수 있는 이메일 또는 URL. 보통 `mailto:본인이메일` 형식이다. 알림을 받을 사용자의 주소가 아니다. | 실제 푸시 설정이 완성되지 않는다. |

알림 설정 없이도 기본 학습은 가능하다. 다만 운영 알림 예약 API는 푸시 설정이 없으면 오류를 반환한다. 키는 브라우저 구독과 연결되므로 매번 새로 생성해 바꾸는 값이 아니다.

### 프로젝트에서 지원하는 추가 변수

| 변수 | 역할 | 현재 코드 기본값 |
|---|---|---|
| `OPENAI_MODEL` | 학습 콘텐츠를 생성할 모델 선택. 음성 모델 선택용은 아니다. | `gpt-6-luna` |
| `AI_INPUT_USD_PER_MILLION` | 입력 토큰 100만 개당 비용 추정에 사용할 달러 단가. | `0.1` |
| `AI_OUTPUT_USD_PER_MILLION` | 출력 토큰 100만 개당 비용 추정에 사용할 달러 단가. | `0.5` |
| `APP_MODE` | 로컬·테스트·운영 동작 구분. | 로컬은 일반 실행으로 동작하며 Vercel에서는 플랫폼의 `VERCEL` 변수로 운영 여부를 자동 판단한다. |

위 모델명과 단가는 현재 코드 설정을 설명한 것이다. 최신 제공자 가격이나 모델 이용 가능성을 검증한 결과가 아니다. 비용 검증 단계에서 실제 사용 모델의 공식 가격과 대조해야 한다.

## 왜 로컬 `.env`에 모두 없어도 실행되는가?

`.env`에 등록하면 안 되는 것이 아니다. 로컬에서도 필요한 설정을 넣을 수 있다. 현재는 기본값이 있는 항목과 운영·알림 전용 항목을 생략한 상태다.

| 설정 위치 | 용도 | 자동 연결 여부 |
|---|---|---|
| `.env` | 내 컴퓨터에서 실행할 때 사용할 실제 설정과 비밀값 | Vercel로 자동 전달되지 않는다. |
| `.env.example` | 지원하는 변수 이름과 예시·기본값을 설명하는 양식 | 실행 시 자동으로 읽히지 않는다. |
| Vercel 환경변수 | Vercel에서 실행되는 배포의 설정 | 내 컴퓨터의 `.env`를 자동 수정하지 않는다. |

현재 서버 코드는 Vercel이 아닌 환경에서, 테스트 모드가 아니고 `.env`가 존재할 때만 그 파일을 읽는다. Vercel에서는 플랫폼이 제공하는 환경변수를 직접 사용한다.

또한 `.env`는 `.gitignore`와 `.vercelignore`에서 제외되어 GitHub와 배포 파일에 들어가지 않는다. GitHub에는 비밀값이 없는 `.env.example`만 공유한다.

예를 들어 로컬의 `APP_URL`은 `http://127.0.0.1:5173`, 운영의 `APP_URL`은 `https://tue111-everyday-voca.vercel.app`이다. 같은 변수라도 실행 장소에 맞게 다른 값을 쓰는 것이 정상이다.

Vercel 환경변수는 Production·Preview·Development별로 적용할 수 있으며, 변경 사항은 새 배포부터 반영된다. 운영 값을 바꾼 뒤에는 재배포한다. [Vercel 환경변수 안내](https://vercel.com/docs/environment-variables)

## 확인한 코드와 문서

- `.env.example`: 변수 목록과 예시
- `server/runtime.ts`: 로컬 파일 로딩, 운영 필수 검사, 기본값과 제공자 설정
- `server/http.ts`: 요청 출처 검사와 예약 작업 인증
- `server/providers.ts`: 콘텐츠 비용 계산과 푸시 발송 설정
- `vercel.json`: 예약 작업 일정
- `docs/HANDOFF_POST_DEPLOY.md`: 남은 검증 순서
